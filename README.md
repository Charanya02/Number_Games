# Number_Games
A variety of number games programmed in Java

## Game 1 - Guess the Number
Program chooses a number between 1 to 100 at random. The user tries to guess the number while program gives them yes or no answers

## Game 2 - Higher or Lower
Program chooses a number between 1 to 100 at random. The user tries to guess the number while program tells them if their number is higher or lower than it's chosen number

## Game 3 - Rock Paper Scissor
Traditional game of stone paper scissors
